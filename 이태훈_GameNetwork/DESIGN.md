# 설계 설명

## 게임 요구사항과 Host·Client가 맡는 역할
### 게임 요구사항
* Client보다 Host가 먼저 접속해 있어야합니다.
* Host 또는 Client가 접속되면 Online 텍스트가 표시되고 SpawnDelay만큼 기다린 후 플레이어 스폰이 되어야 합니다.
* 플레이어 스폰이 완료되면 WASD 이동이 가능해야합니다.
* 플레이어가 코인을 먹으면 해당 플레이어의 Score가 서버에 의해 1씩 증가해야합니다.
* 디스폰된 코인은 SpawnDelay만큼 기다리다가 재스폰이 되어야합니다.
* 영역을 넘을 정도로 많지 않는 이상 스폰될 때 코인끼리도 겹치면 안되고 플레이어끼리도 겹치면 됩니다.

### Host·Client가 맡은 역할
* Host가 맡은 역할은 서버 관리와 스폰, 코인 획득, 스코어 증가입니다.
* Client가 맡은 역할은 플레이어 이동입니다.
